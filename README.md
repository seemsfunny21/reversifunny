# ReversiFunny

Reversi / Othello ως δωρεάν ανεξάρτητη PWA για κινητό και υπολογιστή.

- Παίζεις εναντίον υπολογιστή (3 επίπεδα) ή τοπικά με δεύτερο παίκτη.
- Αυτόματη αποθήκευση, παύση όταν αλλάζεις εφαρμογή και συνέχιση μετά από επανεκκίνηση.
- Ενσωματώνεται στο Applications, στην καρτέλα **Παιχνίδια**, μαζί με το SudokuFunny.

Οι παρτίδες αποθηκεύονται τοπικά στη συσκευή χωρίς λογαριασμό ή βάση δεδομένων. Η διαγραφή των δεδομένων ιστότοπου διαγράφει τις τοπικές παρτίδες.
